# RunTrack 1 : Intégration Web

**Note** : Ce projet a été réalisé dans le cadre de ma formation de Développeur Web et Web Mobile (DWWM) au sein de La Plateforme.

Ce dépôt regroupe mes premiers travaux d'intégration Web (HTML sémantique et CSS). Les exercices sont classés par jour d'apprentissage et montrent une progression allant de la simple structure de documents HTML jusqu'à l'intégration d'une architecture multi-pages complète.

## Contenu du dépôt

- **jour01** : Maquettes initiales (au format PDF) servant de base pour l'intégration de mon CV et de la page de présentation de groupe (Best Beautiful Team).
- **jour02** : Premières intégrations en HTML pur (sémantique). Création de la structure du CV, de la page "Best Beautiful Team", ainsi qu'un projet de groupe présentant les profils de plusieurs étudiants.
- **jour03** : Introduction à la mise en forme CSS. L'exercice démontre notamment l'utilisation de **styles commutables** (`style1.css` et `style2.css`) appliqués à la même structure HTML pour en modifier radicalement le design sans toucher au contenu.
- **jour04** : Réalisation d'une version personnalisée du site de La Plateforme. Ce projet met en pratique l'utilisation approfondie des balises sémantiques HTML5 (`main`, `section`, `article`, etc.), l'intégration de médias et l'application d'un style global via `laplateforme.css` sur plusieurs pages distinctes (`accueil.html`, `ai-school.html`, `contact.html`, etc.).

## Installation et utilisation

L'ensemble de ces projets repose uniquement sur des technologies front-end statiques (HTML5 et CSS3).
1. Clonez le dépôt sur votre machine locale :
   ```bash
   git clone https://github.com/geoffrey-carpentier/runtrack1.git
   ```
2. Parcourez les dossiers selon les jours et ouvrez simplement les fichiers `.html` (comme `accueil.html` ou `bbt.html`) directement dans votre navigateur web pour visualiser le résultat.
